## Selected public repositories

- [**H.264 RTL Encoder**](https://github.com/KevinPequad/h264-rtl-encoder) — synthesizable H.264/AVC RTL with Verilator, FFmpeg validation, and RTL-owned Annex B output.
- [**AV1 RTL Encoder**](https://github.com/KevinPequad/AV1-rtl-encoder) — an end-to-end AV1 encoder implementation focused on RTL-owned, standards-decodable output.
- [**ESP32 USB Wi-Fi PPP**](https://github.com/KevinPequad/esp32-usb-wifi-ppp) — a classic ESP32 used as a Linux network adapter over its USB-to-UART bridge.
- [**Deadlock Linux Dictation**](https://github.com/KevinPequad/deadlock-linux-dictation) — hold-to-dictate voice input for Deadlock on Linux/Proton.
- [**Aerospace Turntable Workflow**](https://github.com/KevinPequad/SeniorProjectGroup5ATurntable2026) — browser-controlled 3D scan-to-inventory tooling for aerospace parts.
